# Nimma-Guru – Community Mentorship & Educational Support Platform

## Overview
Nimma-Guru is an Android-based educational mentorship platform designed to connect retired professionals, teachers, and skilled individuals with students seeking academic guidance and after-school learning support within local communities.

## Features
- Mentor profile management
- Skill-based mentor discovery
- Class and session scheduling
- Community mentorship network
- Student appreciation and feedback system
- Educational session calendar
- Multi-language support concepts

## Technologies Used
- Android Studio
- Java/Kotlin
- Firebase Realtime Database
- ChipGroups UI Components
- Room Database

## Problem Statement
Many experienced retired professionals are willing to share knowledge and mentor students, but there is no organized digital platform to connect them with learners in nearby communities.

## App Workflow
- Mentors create profiles with skills and availability
- Students search mentors based on subjects
- View upcoming mentorship sessions
- Attend local educational classes
- Share appreciation and feedback

## Technical Implementation
- Skill-based search filtering using ChipGroups
- Firebase Realtime Database for mentor management
- Educational dashboard and scheduling system
- Optimized UI for both students and elderly mentors

## Impact Goals
- Improve community-based education support
- Encourage knowledge sharing and mentorship
- Provide meaningful engagement for retired professionals
- Support accessible after-school learning
